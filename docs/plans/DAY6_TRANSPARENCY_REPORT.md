## Publishing the Report

### Step 1: Create Report Directory

```bash
mkdir -p docs/transparency
cd docs/transparency
```

### Step 2: Generate Report with Current Data

```bash
#!/bin/bash
# generate_transparency_report.sh

# Extract statistics from UIDP logs
TOTAL_REVENUE=$(jq '[.transactions[].amounts.total_revenue] | add' ../../dao_treasury_log.json)
CHARITY_ALLOCATION=$(jq '[.transactions[].amounts.charity_allocation] | add' ../../dao_treasury_log.json)
TX_COUNT=$(jq '.transactions | length' ../../dao_treasury_log.json)

# Create report from template with real data
sed -e "s/\[AMOUNT\]/$TOTAL_REVENUE/g" \
    -e "s/\[COUNT\]/$TX_COUNT/g" \
    TRANSPARENCY_REPORT_TEMPLATE.md > TRANSPARENCY_REPORT_v1.0.md

echo "Report generated with current data"
```

### Step 3: Create Proof Chain for Report

```bash
# Sign with GPG
gpg --detach-sign --armor TRANSPARENCY_REPORT_v1.0.md

# Create OpenTimestamps proof
ots stamp TRANSPARENCY_REPORT_v1.0.md

# Calculate SHA-256
sha256sum TRANSPARENCY_REPORT_v1.0.md > TRANSPARENCY_REPORT_v1.0.md.sha256

# Upload to IPFS
REPORT_CID=$(ipfs add -Q TRANSPARENCY_REPORT_v1.0.md)
echo "IPFS CID: $REPORT_CID"

# Create metadata file
cat > transparency_report_metadata.json <<EOF
{
  "version": "1.0",
  "date": "$(date -u +%Y-%m-%dT%H:%M:%SZ)",
  "ipfs_cid": "$REPORT_CID",
  "sha256": "$(cat TRANSPARENCY_REPORT_v1.0.md.sha256 | cut -d' ' -f1)",
  "gpg_signature": "TRANSPARENCY_REPORT_v1.0.md.asc",
  "opentimestamps": "TRANSPARENCY_REPORT_v1.0.md.ots"
}
EOF
```

### Step 4: Publish to Multiple Locations

```bash
# 1. Commit to Git
git add docs/transparency/
git commit -S -m "Publish Transparency Report v1.0"
git push

# 2. Update website
cp TRANSPARENCY_REPORT_v1.0.md ../../docs/index.html  # or create dedicated page

# 3. Upload to IPFS pinning service
# (Pinata, Web3.Storage, etc.)

# 4. Archive on Arweave
arweave deploy TRANSPARENCY_REPORT_v1.0.md --key-file ~/.arweave/wallet.json

# 5. Announce on social media
# Twitter, LinkedIn, etc.
```
